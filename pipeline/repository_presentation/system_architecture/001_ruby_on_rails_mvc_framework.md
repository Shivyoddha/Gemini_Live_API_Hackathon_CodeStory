### Slide 1: Ruby on Rails MVC Framework
- Adheres to the Model-View-Controller (MVC) architectural pattern.
- Core components include:
    - Models: `User`, `DocA`, `DocB` for data management.
    - Controllers: Handling user requests and business logic (e.g., `DocAsController`, `DocBsController`).
    - Views: ERB templates for rendering the user interface.
- Service Layer: `AutoCreateDocBService` encapsulates specific business logic for auto-generating Document B.
