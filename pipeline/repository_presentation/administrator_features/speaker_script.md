## Administrator Features

### Slide 1: Admin Dashboard
For system administrators, a dedicated dashboard is available. This interface is protected and only accessible to users who have been assigned the 'admin' role, ensuring that sensitive management functions are restricted.

### Slide 2: User Management Capabilities
Within the admin dashboard, administrators have the ability to manage all user accounts on the portal. This includes viewing a comprehensive list of all users and, crucially, editing their details. Administrators can modify user display names, update associated email addresses, and reset user passwords, providing full control over user account information.
