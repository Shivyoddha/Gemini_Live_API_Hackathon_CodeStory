## Admin Capabilities

### Slide 1: User Management Interface
The system provides a dedicated administrative dashboard, accessible via the `/admin` route. This interface serves as a central hub for user management. It presents a clear, tabular view of all registered users, listing essential details such as their username, display name, email address, and their assigned role (Buyer, Approver, or Admin), visually distinguished using informative badges. This provides administrators with an immediate overview of the user base and their respective permissions within the system.

### Slide 2: User Profile Editing
Beyond viewing user information, administrators are empowered to modify user profiles directly through the administrative interface. This functionality allows for the updating of a user's display name and their associated email address. Furthermore, administrators can manage user passwords; if a new password and its confirmation are provided, the user's password will be updated. If the password fields are left blank, the existing password remains unchanged, providing a safe way to update other user details without inadvertently locking users out.
