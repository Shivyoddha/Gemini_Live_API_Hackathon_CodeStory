## Frontend & UI Design

### Slide 1: User Interface Aesthetics
The procurement portal boasts a modern and responsive user interface, characterized by a clean gradient design. We've utilized ERB templates for rendering the web pages, integrating inline CSS for styling to ensure a consistent visual theme throughout the application. This approach provides a pleasant and intuitive user experience.

### Slide 2: Key UI Elements
Key elements of the UI include prominently displayed status badges, which use color-coding for immediate visual feedback on document progress. Dashboards are organized to provide clear overviews of pending approvals and document statuses. Forms for creating new documents and for users to approve or reject them are designed to be intuitive and user-friendly. Notably, the login page features a distinct visual theme to establish the application's branding.
