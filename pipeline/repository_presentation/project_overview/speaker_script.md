## Project Overview

### Slide 1: Ruby on Rails Procurement Portal for IRIS
This project is a Ruby on Rails web portal designed to showcase a procurement approval system specifically for IRIS. At its core, it manages a crucial two-document workflow, involving Document A and Document B. This workflow is structured through multiple, sequential approval stages, ensuring that all necessary checks and balances are in place before procurement proceeds.

### Slide 2: Business Value
The primary business value of this system lies in its ability to streamline and formalize the procurement process at IRIS. By enforcing a structured, multi-stage approval chain for equipment purchases, it significantly enhances accountability and transparency. The system ensures that every transaction is trackable, while also making the document handling process more efficient for both the buyers initiating requests and the approvers reviewing them.
